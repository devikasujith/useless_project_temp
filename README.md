# noHelp-ai🎯


## AI That Refuses to Help is a chatbot that becomes increasingly unhelpful the more questions you ask. It uses HTML, CSS, and JavaScript, with no backend or API required.
### Team Name: Axiom


### Team Members
- Team Lead: Fathima Rasha P P - RIT KOTTAYAM
- Member 2: Devika E S - RIT KOTTAYAM


### Project Description
AI That Refuses to Help is a humorous chatbot that becomes increasingly unhelpful as the user asks more questions. Its responses gradually shift from mildly evasive to completely useless, creating a fun and intentionally pointless AI experience.

### The Problem (that doesn't exist)
People are becoming too dependent on AI for simple questions and everyday decisions. Our project solves this completely imaginary problem by creating an AI that gradually refuses to help, encouraging users to think for themselves.

### The Solution (that nobody asked for)
An AI chatbot that gets progressively less helpful the more you ask. Instead of solving your problems, it encourages you to stop asking and figure things out yourself.
